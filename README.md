# Spell Checker for Adobe Photoshop

Скрипт для проверки русской орфографии в редактируемых текстовых слоях Adobe Photoshop.

Spell Checker проверяет все открытые документы, находит ошибки в написании слов, позволяет последовательно переходить между их вхождениями, применять предложенные исправления и добавлять слова в пользовательский словарь.

## Возможности

- проверка орфографии во всех открытых документах;
- поиск повторяющихся слов и некоторых ошибок регистра;
- дополнительная проверка написания ФИО;
- обработка текста во вложенных встроенных смарт-объектах;
- объединение одинаковых ошибок;
- автоматическая замена на предложенный вариант;
- переход к текстовому слою для ручного исправления;
- пользовательский словарь;
- русский и английский интерфейс.

## Требования

- Adobe Photoshop CC2020 и новее;
- Python устанавливается автоматически; без установщика — системный Python 3.10 или новее с компонентом `pip`;
- подключение к интернету.

Скрипт использует Python-библиотеки:

- `requests`;
- `pymorphy3`.

Их подготавливает установщик; при использовании системного Python недостающие библиотеки устанавливаются автоматически при первом запуске.

Для проверки текста используется Яндекс Спеллер. Ключ API не требуется.

## Установка

1. Распакуйте архив и запустите `install_runtime.bat` (Windows 10/11 x64). Выберите обычный режим подключения или режим совместимости с Kaspersky, если он нужен. Python и необходимые библиотеки установятся автоматически.
2. Скопируйте **содержимое папки `Photoshop-files`** в каталог сценариев Photoshop, сохранив папку `lib` целиком:

```text
C:\Program Files\Adobe\Adobe Photoshop <версия>\Presets\Scripts\
```

Структура файлов после копирования:

```text
Spell checker.jsx
lib/
├── spell-checker.pyw
└── exceptions_base.txt
```

3. Перезапустите Photoshop. Команда появится в меню **Файл → Сценарии → Spell checker**.

Для копирования в `Program Files` могут потребоваться права администратора. Установщик окружения, Photoshop и сам скрипт запускаются с обычными правами пользователя.

Общее Python-окружение находится в `%LOCALAPPDATA%\JazzyScripts\SharedRuntime` и может использоваться другими скриптами JazzyScripts. Повторный запуск установщика проверяет готовое окружение и обновляет общий `launcher.vbs`. Этот файл остаётся в папке окружения; копировать его в Photoshop не нужно. Для первой установки нужен интернет.

### Запуск из другой папки

Можно оставить файлы в распакованной папке и выбрать `Photoshop-files/Spell checker.jsx` через **Файл → Сценарии → Обзор...**. Папка `lib` должна оставаться рядом с JSX.

### Использование системного Python

Если общего окружения нет, скрипт использует системный Python 3.10 или новее с компонентом `pip`. Файлы `.pyw` должны быть связаны с Python. Встроенная установка недостающих библиотек сохранена.

## Первый запуск

При первом запуске Python-модуль проверяет наличие `requests` и `pymorphy3`. Если библиотек нет, они устанавливаются автоматически через `pip`.

При использовании системного Python первая проверка поэтому может выполняться дольше обычного. После установки через `install_runtime.bat` библиотеки уже подготовлены.

Для установки библиотек требуется доступ к интернету.

## Использование

1. Откройте документы, которые нужно проверить.
2. Запустите `Файл → Сценарии → Spell checker`.
3. Дождитесь завершения поиска текстовых слоёв.
4. Исправьте найденные ошибки.
5. Закройте окно кнопкой **Готово**.
6. Запустите скрипт повторно для контрольной проверки.

> Скрипт проверяет все открытые документы, а не только активный. Перед запуском закройте документы, которые не должны участвовать в проверке.

## Окно результатов

Каждая строка соответствует одному уникальному ошибочному слову.

Пример:

```text
1/4    ашибка → ошибка    ✎    📖
```

### Счётчик `1/4`

Показывает номер текущего вхождения и общее количество найденных вхождений.

Одно слово может встречаться в разных слоях, документах и смарт-объектах.

### Кнопка `слово → исправление`

Переходит к текущему вхождению и заменяет его на предложенный вариант.

Исправляется только одно вхождение. Для обработки остальных повторно нажимайте кнопку, ориентируясь на счётчик.

### Кнопка `✎`

Открывает нужный документ, выбирает текстовый слой и включает редактирование текста без автоматической замены.

Используйте её, если предложение сервиса неверно или требуется изменить фразу вручную.

### Кнопка `📖`

Добавляет слово в пользовательский словарь.

Подходит для:

- имён и фамилий;
- названий компаний и брендов;
- терминов;
- аббревиатур;
- авторского написания.

Добавленное слово исключается из результатов при следующем запуске проверки.

### Кнопка **Готово**

Закрывает окно результатов.

Список ошибок не обновляется в реальном времени, поэтому после исправлений следует запустить проверку повторно.

## Пользовательский словарь

Словарь хранится не в папке `Program Files`, а в пользовательской папке настроек Photoshop:

```text
spell-checker-user-dictionary.txt
```

Пример расположения в Windows:

```text
C:\Users\<пользователь>\AppData\Roaming\Adobe\
Adobe Photoshop <версия>\
Adobe Photoshop <версия> Settings\
spell-checker-user-dictionary.txt
```

Точный путь определяется через `app.preferencesFolder`.

Для записи в эту папку права администратора не требуются. Файл создаётся автоматически при первом добавлении слова.

Словарь относится к конкретной версии Photoshop. После перехода на новую основную версию его может потребоваться перенести вручную.

Чтобы удалить слово из словаря, откройте файл в текстовом редакторе, удалите соответствующую строку и сохраните файл в кодировке UTF-8.

## Смарт-объекты

Скрипт проверяет текст внутри вложенных встроенных смарт-объектов.

Связанные, заблокированные или недоступные смарт-объекты могут быть пропущены.

При переходе к ошибке Photoshop последовательно открывает необходимые смарт-объекты и выбирает текстовый слой.

Скрипт не сохраняет документы автоматически. После исправления текста внутри смарт-объекта сохраните его обычной командой Photoshop. Для вложенных объектов может потребоваться сохранить изменения на каждом уровне.

## Что проверяется

Скрипт может обнаруживать:

- неизвестные или ошибочно написанные русские слова;
- повторяющиеся слова;
- некоторые ошибки регистра;
- строчное написание распознанных имён, фамилий и отчеств.

Встроенный файл `lib/exceptions_base.txt` содержит базу распространённых имён и других исключений.

Для собственных исключений используйте пользовательский словарь.

## Ограничения

- поддерживается только русский язык;
- требуется подключение к интернету;
- проверяется только редактируемый текст;
- растрированный текст и текст, преобразованный в контуры, не проверяются;
- пунктуация, грамматика и стилистика не анализируются;
- связанные и заблокированные смарт-объекты могут быть недоступны;
- список результатов не обновляется после каждого исправления;
- максимальный объём текста за один запуск — около 500 000 символов;
- предложения Яндекс Спеллера могут быть неточными.

Перед применением автоматической замены учитывайте контекст.

## Конфиденциальность

Для проверки извлечённый текст отправляется в Яндекс Спеллер.

Изображения, PSD-файлы и пиксельные данные не передаются.

Не используйте скрипт для конфиденциальных документов, если передача текста внешнему сервису запрещена требованиями проекта или организации.

Пользовательский словарь хранится локально.

## Устранение проблем

### Python-модуль не запускается

Проверьте, что:

- установка через `install_runtime.bat` завершилась без ошибок;
- при работе без общего окружения — установлен системный Python 3.10 или новее и файлы `.pyw` связаны с ним;
- `spell-checker.pyw` находится в папке `lib`;
- антивирус не блокирует запуск Python.

### Не устанавливаются зависимости

Для общего окружения повторно запустите `install_runtime.bat`.

При использовании системного Python выполните в командной строке:

```bat
python -m pip install requests pymorphy3
```

Если команда `python` не найдена, переустановите Python с включённым флажком **Add Python to PATH**.

### Нет соединения с модулем

Проверьте настройки брандмауэра и антивируса.

Photoshop и Python обмениваются данными локально через `127.0.0.1` и порты `6410` и `6411`.

### Проверка не отвечает

Проверьте подключение к интернету и доступность Яндекс Спеллера в используемой сети.

### Текстовые слои не найдены

Убедитесь, что:

- нужные документы открыты;
- текстовые слои не растрированы;
- текст остаётся редактируемым;
- нужный текст не находится только в недоступном смарт-объекте.

### Исправление не появилось в основном документе

Сохраните открытый смарт-объект. Для вложенных объектов последовательно сохраните изменения на каждом уровне.

## Обновление

1. Закройте Photoshop.
2. Замените `Spell checker.jsx` и папку `lib` файлами новой версии.
3. Сохраните исходную структуру каталогов.
4. Запустите Photoshop снова.

Пользовательский словарь хранится отдельно в папке настроек Photoshop и при обычном обновлении скрипта не удаляется.
