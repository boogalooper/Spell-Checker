# Spell Checker for Adobe Photoshop

Проверка орфографии в текстовых слоях Adobe Photoshop с быстрым переходом к найденным ошибкам, автоматической заменой и пользовательским словарём.

Скрипт предназначен для макетов, в которых текст распределён по множеству слоёв, документов и смарт-объектов. Он собирает текст из всех открытых документов, проверяет его и показывает компактный список проблем. Каждую ошибку можно исправить автоматически, открыть для ручного редактирования или добавить в исключения.

> [!IMPORTANT]
> Проверка выполняется для **всех открытых документов Photoshop**, а не только для активного документа.

## Возможности

- проверка русской орфографии;
- поиск повторяющихся слов;
- обнаружение некоторых ошибок регистра;
- дополнительная проверка написания ФИО и последовательностей имён;
- обработка всех текстовых слоёв в открытых документах;
- поиск текста внутри вложенных встроенных смарт-объектов;
- объединение одинаковых ошибок в одну строку;
- переход между всеми вхождениями найденного слова;
- автоматическая замена на предложенный вариант;
- переход к текстовому слою для ручного исправления;
- пользовательский словарь для имён, терминов, брендов и другой специальной лексики;
- русский и английский язык интерфейса;
- сохранение оформления текста при автоматической замене, насколько это позволяет структура текстового слоя Photoshop.

## Как работает проверка

После запуска скрипт:

1. просматривает все открытые документы;
2. находит обычные текстовые слои;
3. проверяет доступные встроенные смарт-объекты, включая вложенные;
4. отправляет извлечённый текст на проверку;
5. объединяет одинаковые ошибки;
6. открывает окно с результатами.

Документы не объединяются и не перестраиваются. Во время поиска содержимое смарт-объектов анализируется без сохранения временных изменений в исходных документах.

## Требования

Для работы необходимы:

- Adobe Photoshop с поддержкой сценариев JSX/ExtendScript;
- Python 3;
- подключение к интернету;

При первом запуске Python-модуль автоматически пытается установить недостающие пакеты:

- `requests`;
- `pymorphy3`.

Поэтому первая проверка может запускаться дольше обычного.

## Установка

### 1. Скачайте репозиторий

Скачайте архив проекта и распакуйте его в постоянную папку.

Не изменяйте взаимное расположение файлов:

```text
Spell checker.jsx
lib/
├── spell-checker.pyw
└── exceptions_base.txt
```

Файл `Spell checker.jsx` должен находиться рядом с папкой `lib`.

### 2. Установите Python

Установите Python 3 с поддержкой `pip`.

В Windows рекомендуется сохранить стандартную ассоциацию файлов `.pyw` с Python. Скрипт Photoshop использует эту ассоциацию для автоматического запуска модуля проверки.

### 3. Добавьте скрипт в Photoshop

Для постоянной установки скопируйте файл `Spell checker.jsx` и папку `lib` в каталог сценариев Photoshop:

```text
Adobe Photoshop/Presets/Scripts/
```

Для записи в папку установленной программы могут потребоваться права администратора.

После копирования перезапустите Photoshop. Команда появится в меню:

```text
Файл → Сценарии → Spell checker
```

### Запуск без установки

Скрипт также можно запустить непосредственно из распакованной папки:

```text
Файл → Сценарии → Обзор...
```

Выберите файл `Spell checker.jsx`.

При таком способе папка `lib` всё равно должна оставаться рядом со скриптом.

## Быстрый старт

1. Откройте один или несколько документов с текстовыми слоями.
2. Убедитесь, что среди открытых документов нет макетов, которые не нужно проверять.
3. Запустите `Spell checker`.
4. Дождитесь завершения поиска текстовых слоёв.
5. Просмотрите найденные ошибки в окне результатов.
6. Исправьте слова автоматически или перейдите к ним для ручного редактирования.
7. После завершения нажмите **Готово**.
8. Запустите проверку повторно, чтобы получить обновлённый список.

Если ошибок нет, скрипт покажет сообщение об успешном завершении проверки.

## Окно результатов

Для каждого уникального ошибочного слова отображается отдельная строка.

Пример:

```text
1/4    ашибка → ошибка    ✎    📖
```

### Счётчик `1/4`

Показывает текущее вхождение и общее количество найденных вхождений этого слова.

Одинаковое слово может встречаться:

- несколько раз в одном текстовом слое;
- в разных слоях;
- в разных документах;
- внутри смарт-объектов.

После каждого перехода или исправления скрипт автоматически выбирает следующее вхождение. После последнего вхождения счётчик возвращается к первому.

### Кнопка `слово → исправление`

Нажатие на основную кнопку:

1. открывает документ с текущим вхождением;
2. выбирает нужный текстовый слой;
3. приближает область слоя;
4. заменяет слово на предложенный вариант;
5. переходит к следующему вхождению в списке.

Если сервис не предложил замену, на кнопке отображается только найденное слово. В этом случае используйте ручное редактирование или добавьте слово в словарь.

> [!NOTE]
> Автоматическая замена применяется только к текущему вхождению. Для исправления всех повторов нажмите кнопку несколько раз, ориентируясь на счётчик.

### Кнопка `✎`

Переходит к текущему вхождению без автоматической замены:

- открывает нужный документ;
- выбирает текстовый слой;
- приближает его;
- включает инструмент редактирования текста.

Эта команда удобна, когда:

- предложенное исправление неверно;
- нужно изменить не одно слово, а всю фразу;
- требуется проверить контекст;
- для слова нет готовой подсказки.

### Кнопка `📖`

Добавляет найденное слово в пользовательский словарь.

Используйте её для:

- имён и фамилий;
- названий компаний;
- торговых марок;
- географических названий;
- профессиональных терминов;
- аббревиатур;
- авторского написания.

После добавления кнопка словаря для этой строки отключается. Новое исключение учитывается при следующем запуске проверки.

### Кнопка **Готово**

Закрывает окно результатов. Она не запускает повторную проверку и не сохраняет документы автоматически.

## Повторная проверка

Окно результатов отражает состояние текста на момент запуска скрипта. Список не перестраивается после каждого исправления.

После внесения изменений рекомендуется:

1. закрыть окно кнопкой **Готово**;
2. сохранить необходимые документы и смарт-объекты;
3. запустить скрипт ещё раз.

Повторный запуск покажет только оставшиеся проблемы.

## Работа с несколькими документами

Скрипт обрабатывает все документы, открытые в Photoshop на момент запуска.

Это удобно для проверки серии связанных макетов, но требует внимания:

- закройте документы, которые не нужно проверять;
- не ориентируйтесь только на активную вкладку;
- при выборе ошибки Photoshop может автоматически переключиться на другой документ.

После первоначального поиска скрипт возвращает активным документ, который был выбран до запуска. При работе со списком результатов активный документ меняется в зависимости от расположения выбранной ошибки.

## Работа со смарт-объектами

Скрипт умеет искать текст внутри вложенных **встроенных** смарт-объектов.

Во время первоначального сканирования Photoshop может кратковременно выполнять дополнительные операции. Скрипт использует историю документа, чтобы не оставлять после анализа временно развёрнутые слои.

При переходе к ошибке внутри смарт-объекта:

1. открывается содержимое смарт-объекта;
2. при необходимости последовательно открываются вложенные объекты;
3. выбирается текстовый слой с найденным словом;
4. выполняется замена или включается ручное редактирование.

### Сохранение изменений в смарт-объекте

Скрипт не сохраняет открытые документы автоматически.

После исправления текста внутри смарт-объекта сохраните его обычной командой Photoshop. Для вложенных объектов может потребоваться последовательно сохранить и закрыть несколько вкладок, чтобы изменения дошли до основного документа.

### Какие смарт-объекты могут быть пропущены

Автоматический поиск внутри смарт-объекта может быть недоступен, если объект:

- связан с внешним файлом;
- заблокирован;
- не может быть открыт или преобразован Photoshop;
- содержит структуру, которую Photoshop не позволяет обработать через сценарии.

Обычные текстовые слои основного документа при этом продолжают проверяться.

## Пользовательский словарь

Пользовательский словарь создаётся автоматически в папке настроек Photoshop под именем:

```text
spell-checker-user-dictionary.txt
```

Каждое слово хранится на отдельной строке. Регистр при добавлении не учитывается.

Словарь:

- хранится локально;
- используется при последующих проверках;
- дополняет встроенную базу исключений;
- не заменяется при обновлении файлов скрипта.

### Как удалить слово из словаря

В интерфейсе предусмотрено только добавление слов.

Чтобы удалить исключение:

1. закройте окно проверки;
2. найдите `spell-checker-user-dictionary.txt` в папке настроек Photoshop;
3. откройте файл в текстовом редакторе;
4. удалите нужную строку;
5. сохраните файл в кодировке UTF-8;
6. запустите проверку повторно.

Можно также удалить весь файл. При следующем добавлении слова он будет создан заново.

## Встроенная база исключений

Файл `lib/exceptions_base.txt` содержит расширенный список имён, фамилий и других слов, которые не должны считаться орфографическими ошибками.

Эта база также помогает скрипту распознавать последовательности, похожие на ФИО, и находить случаи, когда имя или фамилия написаны со строчной буквы.

Обычно редактировать этот файл не требуется. Для собственных исключений используйте кнопку `📖`.

## Что проверяет скрипт

Скрипт может обнаруживать:

- неизвестные или ошибочно написанные русские слова;
- повторяющиеся слова;
- некоторые ошибки регистра;
- неправильный регистр в распознанных сочетаниях имён, фамилий и отчеств.

Например:

```text
ашибка → ошибка
текст текст → повтор слова
иванов иван → Иванов Иван
```

Результат зависит от контекста и предложений сервиса проверки. Любую автоматическую замену следует оценивать перед применением.

## Что скрипт не проверяет

Скрипт не является полноценным литературным редактором. Он не предназначен для проверки:

- пунктуации;
- сложной грамматики;
- стилистики;
- логики текста;
- согласования длинных фраз;
- типографики;
- переносов;
- корректности дат, чисел и фактов;
- текста, превращённого в растровое изображение или векторные контуры;
- текста в закрытых документах;
- языков, отличных от русского.

Знаки препинания и служебные символы используются преимущественно как разделители и сами по себе не анализируются.

## Интернет и конфиденциальность

Для проверки используется внешний сервис Яндекс Спеллер.

На сервер отправляется извлечённый текст из проверяемых текстовых слоёв. Изображения, содержимое PSD как файла и пиксельные данные не отправляются.

Не запускайте скрипт для документов с конфиденциальным текстом, если передача этого текста внешнему сервису запрещена правилами вашей организации или требованиями проекта.

Пользовательский словарь хранится локально в папке настроек Photoshop.

## Ограничения

- Проверяется только русский язык.
- Для проверки требуется доступ в интернет.
- Общий объём подготовленного текста ограничен примерно 500 000 символов за один запуск.
- Результаты зависят от Яндекс Спеллера и могут содержать ложные срабатывания.
- Не для каждой ошибки доступен вариант автоматической замены.
- Список результатов не обновляется в реальном времени.
- Заблокированные и связанные смарт-объекты могут быть пропущены.
- Скрипт не сохраняет документы и смарт-объекты автоматически.
- Если текст изменился после проверки, отдельные старые результаты могут больше не находиться в исходном слое.

## Назначение горячей клавиши

Для регулярного использования можно назначить команде сочетание клавиш средствами Photoshop:

1. откройте редактор клавиатурных сокращений;
2. выберите команды меню приложения;
3. найдите раздел `Файл → Сценарии`;
4. выберите `Spell checker`;
5. назначьте свободное сочетание клавиш.

Название и расположение команды могут немного отличаться в разных версиях Photoshop.


## Решение проблем

### Скрипт сообщает, что нет открытых документов

Откройте хотя бы один документ Photoshop и повторите запуск.

### Текстовые слои не найдены

Проверьте, что:

- текст остаётся редактируемым;
- слой действительно является текстовым;
- текст не растрирован;
- нужный документ открыт;
- текст не находится только в недоступном связанном или заблокированном смарт-объекте.

### Модуль `spell-checker` не найден

Убедитесь, что рядом с `Spell checker.jsx` находится папка `lib`, а внутри неё — файл `spell-checker.pyw`.

Правильная структура:

```text
Spell checker.jsx
lib/spell-checker.pyw
lib/exceptions_base.txt
```

### Не удаётся установить соединение с модулем

Проверьте:

- установлен ли Python 3;
- запускаются ли файлы `.pyw`;
- не блокирует ли запуск антивирус;
- разрешены ли локальные соединения для Photoshop и Python;
- не заняты ли используемые скриптом локальные порты другой программой.

После устранения причины полностью закройте зависший процесс Python, если он остался активным, и повторите запуск.

### Первая проверка долго запускается

При первом запуске могут автоматически устанавливаться Python-пакеты. Дождитесь завершения установки.

Если установка завершилась ошибкой, проверьте:

- доступ к интернету;
- наличие `pip`;
- права на установку пакетов;
- настройки прокси;
- работу команды установки пакетов в используемой версии Python.

### Проверка недоступна или не отвечает

Убедитесь, что доступен интернет и не заблокирован Яндекс Спеллер.

Также проверьте настройки брандмауэра, прокси и корпоративной сети.

### Автоматическое исправление не найдено в слое

Такое возможно, если после проверки:

- текст уже был изменён вручную;
- слово было исправлено другим действием;
- слой был удалён или заменён;
- изменилась структура документа;
- смарт-объект был закрыт без сохранения;
- в документе появилось несколько неоднозначных вариантов.

Перейдите к слою вручную, исправьте текст и запустите проверку повторно.

### Слово снова появляется после добавления в словарь

Закройте текущие результаты и запустите скрипт заново. Уже открытый список не обновляется автоматически.

Если слово продолжает появляться, проверьте наличие соответствующей строки в `spell-checker-user-dictionary.txt`.

### Исправление в смарт-объекте не появилось в основном документе

Сохраните открытое содержимое смарт-объекта. Для вложенных объектов сохраните изменения на каждом уровне, затем вернитесь в основной документ.

### Ошибка появляется только иногда

Скрипт объединяет данные из всех открытых документов. Перед повторной проверкой убедитесь, что набор открытых документов не изменился.

## Рекомендуемый рабочий процесс

Для надёжной проверки большого проекта:

1. сохраните исходные документы;
2. откройте только связанные макеты;
3. запустите проверку;
4. сначала добавьте корректные имена и термины в словарь;
5. применяйте очевидные автоматические исправления;
6. спорные случаи открывайте кнопкой `✎`;
7. сохраняйте изменения внутри смарт-объектов;
8. закройте окно результатов;
9. запустите повторную проверку;
10. завершите работу, когда скрипт сообщит, что ошибок не найдено.

---

Spell Checker помогает быстро найти типичные орфографические ошибки в сложных Photoshop-макетах, но окончательное решение об исправлении всегда остаётся за пользователем.
